# Sistem Manajemen Inventaris Obat & Peringatan Kedaluwarsa

Aplikasi desktop berbasis C++ dan Qt Widgets untuk mengelola stok obat apotek, memantau masa kedaluwarsa secara otomatis menggunakan indikator visual, serta menerapkan prioritas pengeluaran obat berbasis metode **FEFO (_First Expired, First Out_)**.

Proyek ini dibuat sebagai Tugas Akhir Semester 1 Algoritma dan Pemrograman.

---

## 💻 Teknologi yang Digunakan

- **Bahasa Pemrograman:** C++ (C++17)
- **Framework Antarmuka (GUI):** Qt Widgets (Qt 6)
